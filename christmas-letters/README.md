# 크리스마스 큰 글자 만들기 (참빛예수)

`index.html` **파일 하나**만 다른 컴퓨터(인쇄용)로 옮겨서 더블클릭하면 됩니다. 글꼴 21종(붓글씨 추천 포함)이 파일 안에 들어 있어 인터넷이 필요 없습니다.

- 기본은 검정 단색(잉크 절약). 글자 입력 → 글꼴 선택 → 🖨 인쇄 (글자 1개 = 1페이지)
- 인쇄 창: 배율 100%, 머리글/바닥글 끄기
- "나눠 인쇄"로 한 글자를 A4 여러 장(2×2~4×4)에 나눠 뽑아 붙여서 크게 만들기
- 뒤에서 보이게 붙일 때만 '좌우반전' 켜기
- 'PNG 저장'으로 글자별 이미지 파일도 만들 수 있음
- 폰트 출처: Google Fonts (SIL OFL, 상업/교회 사용 가능), 한글 2,350자로 경량화
