# 크리스마스 큰 글자 만들기 (참빛예수)

웹 주소로 열어서 사용합니다 (글꼴 79종은 선택할 때 `fonts/` 폴더에서 불러옵니다).

- 글자 입력 → 글꼴 선택(붓글씨/손글씨/둥근/제목체/고딕/명조 분류) → 🖨 인쇄 (글자 1개 = 1페이지)
- "글자 나누기 → 자음·모음 하나씩": 참 → ㅊ, ㅏ, ㅁ 각각 1페이지
- "나눠 인쇄"로 한 글자를 A4 여러 장(2×2~4×4)에 나눠 뽑아 붙여서 크게 만들기
- 기본은 검정 단색, 좌우반전 지원
- 인쇄 창: 배율 100%, 머리글/바닥글 끄기
- 폰트 출처: Google Fonts (SIL OFL), 한글 2,350자 + 자모로 경량화 (`fonts/*.woff2`)
